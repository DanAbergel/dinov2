DINOv2 ablation results — Imagenette & HCP

Loss curves and linear-probe scores for every run. Part 1: Imagenette (control on natural images). Part 2: HCP brain MRI.

Metric. All scores are a linear probe on frozen features. The loss curve is shown for reference only — a flat or rising loss can still give the best probe, and a loss diving to 0 indicates collapse.

Part 1

Imagenette — control on natural images

9,469 images, 10 classes. Probe = linear classification of the 10 classes (validation accuracy, chance = 10%).

Test 1 · Default configuration

DINOv2 out of the box

9,469 images65,536 prototypesteacher_temp 0.04koleo on

Original ImageNet-scale hyperparameters, unchanged.

ResultLoss flat throughout; probe 41% (chance 10%).

Test 2 · Prototypes + temperature

Fewer prototypes, sharpened temperature

4,096 prototypesteacher_temp 0.04 → 0.02koleo = 0

Prototypes cut to 4,096, teacher temperature sharpened toward the end (0.04 → 0.02), koleo disabled.

ResultLoss drops 9.6 → 3.8; probe 71.3% (+30 vs default).
Part 2

HCP — brain MRI

Each fMRI scan → 2D axial brain slices. Probe = sex prediction (chance = 50%), 5-fold CV by subject. Two changes are tested alone and combined — A: full-view crops (local = global); B: 8 timepoints per scan (multi-frame). Everything else is fixed (4096 prototypes, koleo = 0, temp 0.01 → 0.04).

Test 1 · Baseline

One image per scan, standard crops

1 image / scanstandard crops 96px

One temporal-mean image per scan, standard DINO crops. The reference.

ResultProbe 77.4% ± 1.4.

Test 2 · Change A

Full-view local crops (local = global)

1 image / scanlocal = global

Local crops enlarged to full view instead of small 96px crops.

ResultProbe 79.1% ± 2.3 · +1.7 vs baseline.

Test 3 · Change B

Eight timepoints per scan (multi-frame)

multi-frame (8 / scan)standard crops 96px

Eight slices at eight timepoints instead of one mean image.

ResultProbe 75.6% ± 1.7 · −1.8 vs baseline (hurts alone).

Test 4 · A + B

Multi-frame + full-view crops

multi-frame (8 / scan)local = global

Both changes together.

ResultProbe 80.1% ± 2.1 · best result.

Summary

Imagenette — the probe reacts strongly to hyperparameters: 41% → 71%.

HCP — full-view crops (A) help (+1.7); multi-frame (B) hurts on its own (−1.8); together they give the best result, 80.1%.

Next — the brain probe moves far less than Imagenette's. The likely lever is a real gap between the two views: different temporal windows per view (± 3D augmentations).

Probe = linear classification on frozen features · HCP: sex, 5-fold CV by subject, chance 50% · Imagenette: 10 classes, chance 10% · All runs: 4096 prototypes, koleo = 0.
